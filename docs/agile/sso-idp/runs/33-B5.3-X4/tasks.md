### T1 — DEBT-189 (F1–F4)
- **F1 `reauthAfter` tổng quát** (`authorize.service.ts` `handle`): khi tạo login context, `reauthAfter = max(prompt=login ? now : -∞, maxAge !== undefined ? now - maxAge*1000 : -∞)`, bỏ qua nếu cả hai không có. Áp dụng **kể cả khi chưa có session** (chính là lỗi DEBT-189). `max_age=0` ⇒ `now` (giữ step-up admin). Không thêm field mới vào context; `resume` giữ nguyên kiểm `session.authTime < ctx.reauthAfter`.
- **F2 Leg Google**: `FederationStateRecord` mang `reauthAfter?: number` (thay cờ `reauth` + mốc `createdAt`); `buildAuthorizeUrl` gửi `max_age = max(0, floor((now - reauthAfter)/1000))`; `verifyGoogleIdToken` dùng `reauthSince = reauthAfter` (skew 60s giữ nguyên; thiếu `auth_time` ⇒ `reauth_required`). GitHub: có `reauthAfter` ⇒ ẩn nút + `start` từ chối (đã có, giờ phủ cả `max_age`).
- **F3 `auth_time` thật**: thêm `CreateSessionOptions.authTime?: number` (server-only). Google có `auth_time` ⇒ session `authTime = clamp(auth_time*1000, [reauthAfter ?? -∞, now])` (kẹp dưới bởi `reauthAfter` chỉ để hấp thụ skew ≤ 60s, nếu không resume sẽ `login_required` oan). Google không có `auth_time` (không yêu cầu) và GitHub ⇒ `now` (giới hạn đã biết → DEBT-192). Login local không đổi.
- **F4 Acceptance bổ sung**: int `max_age=60` không session: Google `auth_time = now-3600` ⇒ trang lỗi `reauth_required`, không session; `auth_time = now-10` ⇒ code; ID token `auth_time` == `auth_time` provider (±1s), KHÔNG phải thời điểm callback; URL start chứa `max_age` đúng; GitHub start với context `max_age` ⇒ 400 `reauth_required`; admin step-up `prompt=login&max_age=0` không hồi quy; test cũ pin hành vi DEBT-189 phải đảo kỳ vọng. Mutation ⇒ RED: bỏ nhánh "không session" ở F1; bỏ clamp/F3.
